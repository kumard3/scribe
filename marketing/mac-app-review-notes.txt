BOLKIT FOR MAC, REVIEW NOTES

NO ACCOUNT, NO PURCHASES
No account, login, backend, purchase or subscription; no demo credentials needed.

WHAT IT DOES
Dictation and meeting transcription. Hold a key, speak, let go, and the text is pasted into the app you are typing in. It can also record a call and transcribe it with speakers separated. Models run on the Mac, it works offline.

HOW TO REACH THE MAIN FEATURES
1. Launch. Bolkit lives in the menu bar (microphone icon). A setup guide asks for Microphone, Speech Recognition, Accessibility and Input Monitoring.
2. Open TextEdit, hold fn (Globe), speak, let go: the transcript is pasted at the cursor. Control-Option-Space toggles dictation. No download needed (Apple's recognizer is the default).
3. Menu bar > Record meeting… opens the Recorder. Pick "No screen" (audio only) or a screen/window thumbnail, then Start recording. macOS asks to record system audio (and Screen Recording if a screen is picked). An indicator at the top shows the timer and Stop; results appear under Dashboard > Meetings.
4. Menu bar > Record screen… records only the screen (with mic and Mac sound) to Movies > Bolkit,.
5. Optional: when a call app (Zoom, Teams, Meet) turns on the mic, a "Record this meeting?" card appears. Nothing records until the user presses Record; it can be turned off.
6. Menu bar > Transcribe audio file. Dashboard > Models lists optional offline model downloads.

WHY EACH PERMISSION
- Microphone and Speech Recognition: dictation with Apple's recognizer.
- Accessibility: when the user stops speaking, Bolkit puts their own transcript on the pasteboard and posts one Command-V (CGEvent post) so it lands in their app. It does not use AXUIElement and never reads other apps' content. Without it the transcript is only copied.
- Input Monitoring: a listen-only tap on modifier changes (flagsChanged), so holding fn starts and stops dictation. No other keystrokes are read or stored.
- System audio: only during a meeting recording the user starts, for the other side of the call.
- Screen Recording: only when the user picks a screen or window in the Recorder (ScreenCaptureKit); thumbnails use the same permission. Recordings stay on the Mac.
- Movies folder (assets.movies.read-write): screen-only recordings go to Movies > Bolkit.
- Mic-in-use check: reads which apps have the mic open (Core Audio process list) only to offer the card above. Nothing is stored or sent.

EXTERNAL SERVICES
Apple Speech; Apple Foundation Models on device for summaries; Hugging Face and GitHub Releases for static downloads of optional models; optionally Ollama, a local server the user runs, for text cleanup. New and optional: Microsoft Azure Speech with the user's own Azure key, under Dashboard > Models > Azure (cloud). Off by default; the card states that audio is sent to Microsoft; no key ships in the app, we never receive the audio, and no key is needed to review. No auth provider, payments, analytics, ads, crash reporting or backend of ours.

REGIONAL DIFFERENCES
None.

REGULATED INDUSTRY AND THIRD-PARTY MATERIAL
Not regulated; a productivity utility. Models are public open-weight releases (Whisper, NVIDIA NeMo, Google Gemma, public open-weight licenses). Source is MIT at https://github.com/kumard3/scribe.

TESTED ON
MacBook Pro 14-inch (M3 Pro), macOS 27.0. Build 1.3.5 (11) ran in the App Sandbox. New since 1.3.4: saying "delete everything I said" while dictating clears the earlier words; an optional on-device model applies spoken self-corrections (removals only); Recorder thumbnails update live, hovering one outlines that screen or window, and a red border with a "Bolkit is recording" label marks what is captured (excluded from the capture); Dashboard > Home shows local stats (word counts, speaking speed, streak, count of the user's own Azure requests), stored only on the Mac. Needs macOS 14.0+ (meeting recording 14.4+, screen recording 15+).
