BOLKIT FOR MAC, REVIEW NOTES

NO ACCOUNT, NO PURCHASES
There is no sign up, login, account, or account deletion flow, because the app has no accounts and no backend. No in-app purchase or subscription. No demo credentials needed. The iPhone version of Bolkit is already on the App Store under this same app record.

WHAT IT DOES
Bolkit is a dictation and meeting transcription app for the Mac. Hold a key, speak, let go, and the text is pasted into the app you are typing in. It can also record a call and transcribe it with the speakers separated. The speech models run on the Mac, it works with the network off, and we operate no server.

HOW TO REACH THE MAIN FEATURES
1. Launch. Bolkit lives in the menu bar (the microphone icon); it has no Dock icon. A setup guide opens on first launch.
2. The setup guide asks for Microphone and Speech Recognition, then Accessibility and Input Monitoring. Why each one is needed is explained below.
3. Open TextEdit, hold the fn (Globe) key, speak, and let go. The transcript is pasted at the cursor. Control-Option-Space starts and stops dictation without holding a key. No download is required: the default engine is Apple's built-in speech recognizer.
4. Menu bar > Record meeting… opens the Recorder window. Pick "No screen" (audio only) or a screen/window thumbnail to record with the call, then Start recording. macOS asks for permission to record system audio (and Screen Recording if a screen is picked). A small indicator at the top of the screen shows the timer and a Stop button; the transcript, speakers, summary and screen video appear under Dashboard > Meetings.
5. Menu bar > Record screen… records only the screen (with mic and Mac sound) to Movies > Bolkit, playable under Dashboard > Screen.
6. Optional: when a call app (Zoom, Teams, a browser on Google Meet) turns on the microphone, Bolkit shows a small "Record this meeting?" card. Nothing is recorded until the user presses Record. It can be turned off in Dashboard > Meetings.
7. Menu bar > Transcribe audio file: pick an audio file and get a transcript.
8. Dashboard > Models: every entry other than the built-in ones is an optional one-time download of an offline speech model.

WHY EACH PERMISSION
- Microphone: to hear the user.
- Speech Recognition: Apple's on-device recognizer is the default engine.
- Accessibility: when the user stops speaking, Bolkit puts their own transcript on the pasteboard and posts one Command-V keystroke (CGEvent post) so the text lands in the app they are typing in. It does not use the Accessibility API (AXUIElement) and never reads other apps' content. Voice typing is itself an accessibility aid: it lets people with RSI or limited hand use enter text in any app. Without this permission the transcript is only copied to the clipboard.
- Input Monitoring: a listen-only event tap on modifier key changes (flagsChanged only), so holding fn can start and stop dictation. No other keystrokes are read or stored.
- System audio recording: only when the user starts a meeting recording, to capture the other side of the call as its own track.
- Screen Recording: only when the user picks a screen or window to record in the Recorder (ScreenCaptureKit). The thumbnails in the Recorder and the on-device Apple Intelligence suggestion of which window is the call use the same permission. Recordings stay on the Mac.
- Movies folder (assets.movies.read-write): screen-only recordings are saved to Movies > Bolkit so the user can find them in Finder.
- Microphone-in-use check: Bolkit reads which apps currently have the microphone open (Core Audio process list) only to offer the "Record this meeting?" card. Nothing is stored or sent.

EXTERNAL SERVICES
- Apple Speech framework (SFSpeechRecognizer, SpeechAnalyzer), the default engine.
- Apple Foundation Models, on device, for meeting summaries when Apple Intelligence is turned on.
- Hugging Face and GitHub Releases: static file downloads only, for the optional offline models. Nothing is sent up.
- Optional: Ollama, a local server the user runs on their own Mac, for text cleanup.
No authentication provider, payment processor, analytics, advertising SDK, crash reporting, or backend operated by us.

REGIONAL DIFFERENCES
None. Identical behaviour in every region, no geofenced features, no regional pricing.

REGULATED INDUSTRY AND THIRD-PARTY MATERIAL
Not a regulated industry; a productivity utility with no health, financial, gambling or medical functionality. All speech models are publicly released open-weight models (Whisper, MIT; NVIDIA NeMo via k2-fsa/sherpa-onnx, Apache 2.0/CC-BY; Google Gemma, Gemma Terms of Use). The downloaded files are model weights, not executable code. Our source is MIT and public at https://github.com/kumard3/scribe.

TESTED ON
MacBook Pro 14-inch (M3 Pro, Mac15,6), macOS 27.0 (26A428). Before submitting we ran build 1.3.3 (7) inside the App Sandbox on this Mac: a meeting recording with system audio and a screen clip, switching the shared window mid-call, and a screen-only recording to Movies > Bolkit all worked. Earlier, build 1.3.2 (6) was run in the sandbox: it launches without asking for any permission until the setup guide does, and its self-tests pass. The same code downloads models into its container and transcribed and summarised a recorded four-person test call. Needs macOS 14.0+ (meeting recording 14.4+), Apple silicon or Intel.
